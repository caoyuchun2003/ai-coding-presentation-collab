# AI 项目分享协作仓库

两位分享人的内容已经合并为一个内容型 Web PPT，顶部可以切换两个章节；同时保留独立目录，方便各自修改、预览和合并。

## 内容分工

- `presenter-1-yesterday/website/`：合并后的主站，包含两位分享人的完整内容。
- `presenter-2-project-docs/website/`：第二位分享人的独立 Web 草稿，便于单独修改项目文档部分。

两个网站都采用项目文档 PPT 的视觉方向：深蓝、白底、橙色强调、清晰的文档层级。

## 本地预览

进入对应目录后运行 `npm install` 和 `npm run dev`。建议各自在自己的目录内修改，涉及两套网站共用的内容或样式时，再通过 Pull Request 合并讨论。
