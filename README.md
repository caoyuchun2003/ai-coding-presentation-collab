# AI 项目分享协作仓库

两位分享人的内容统一采用 Web 形式，分别放在独立目录中，方便各自修改、预览和合并。

## 内容分工

- `presenter-1-yesterday/website/`：第一位分享人，昨天的 AI 编程 Agent 观察与选型内容。
- `presenter-2-project-docs/website/`：第二位分享人，AI 接手项目时的文档入口与代码库导航内容。

两个网站都采用项目文档 PPT 的视觉方向：深蓝、白底、橙色强调、清晰的文档层级。

## 本地预览

进入对应目录后运行 `npm install` 和 `npm run dev`。建议各自在自己的目录内修改，涉及两套网站共用的内容或样式时，再通过 Pull Request 合并讨论。
